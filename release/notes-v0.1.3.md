# Exvius Offline v0.1.3

New games now start with the opening sequence instead of treating the tutorial and Earth Shrine Entrance as already completed.

- Removed the old forced tutorial and first-stage completion flags.
- Login now loads the current campaign's progress before the game opens, including when starting a new campaign.
- Existing campaigns keep their progress when updating. Use New Game only if you want to start again. The previous campaign is backed up automatically.

The opening movie is included in the downloaded game data. This update reuses your existing data download.

Known issues carried over: startup is still slightly over one minute on the test phone, and the Home TAP graphic and some shop header artwork still need fixes.
