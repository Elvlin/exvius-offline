# Exvius Offline v0.1.1

The APK is now about **74 MB**, down from 148 MB. Startup art, fonts and other game resources are downloaded with the rest of the game data instead of being packed inside the app.

The APK is also available directly in the [release folder](./).

The first launch still downloads everything automatically. Existing data packs are reused, so this update adds one resource pack instead of downloading all the old packs again. Once installed, the game can use these resources offline.

Your existing campaign is kept when you install this update over the previous app.

The README now explains repeatable Lapis rewards, summon and event season selectors, solo raid progress, Lapis-priced bundles and other offline changes. Screenshots show both season dropdowns open.
