# Exvius Offline v0.1.0 Preview

An unofficial fan project for playing the preserved Final Fantasy Brave Exvius Global client offline.

## Download

Install **exvius-offline-v0.1.0.apk**, then open the app with an internet connection. It downloads and installs the complete game data automatically. The initial data download is approximately **14.4 GB**. Allow around **18 GB of free space** for installation.

After setup, gameplay uses the files on your device. There is no need to choose chapters or events to download separately.

## Included in this preview

- Original Global game interface with local campaign saves and game logic.
- Preserved story, towns, explorations and event content.
- Supported local summons, shops, crafting, raids and other game systems.
- A smaller APK with game data kept separately for easier updates.
- Automatic version checks when connected, with offline play using installed data.
- Repairs to Home navigation, missing artwork and Esper training layout cleanup.

This is still a work in progress. Some advanced systems and archived event interactions remain incomplete, and loading can be slow on some devices. Official accounts and online services are not restored.

Install future app updates over the existing app to keep your save. Android requires its usual confirmation for APK installation. Uninstalling can erase local progress.
