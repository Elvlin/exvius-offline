# Download Exvius Offline

## [Download the APK (74 MB)](https://github.com/Elvlin/exvius-offline/raw/refs/heads/main/release/exvius-offline-v0.1.1.apk)

The APK file is **[exvius-offline-v0.1.1.apk](exvius-offline-v0.1.1.apk)** in this folder.

Install it, then open it with an internet connection. It downloads all the game data automatically, about **14.5 GB**. After setup, you can play offline.

Allow about **18 GB of free space** for setup. If the download stops, reopen the app to continue.

Install future APKs over the existing app to keep your save. Uninstalling the app can erase it.
