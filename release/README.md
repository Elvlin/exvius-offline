# Releases

Download the latest APK from [GitHub Releases](https://github.com/Elvlin/exvius-offline/releases).

Install the APK, then open it with an internet connection for the automatic game data download. After setup, the game can be played offline.

Install future APKs over your existing installation to keep your local save. Android asks you to confirm the installation.

The complete data download is described in [`data/latest.json`](../data/latest.json). Large APK and data files are release attachments rather than files committed to this folder.
