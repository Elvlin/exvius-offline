**Exvius Offline v0.1.36**

**Fixes**
- Fixed Lapis not being awarded again when repeating cleared stages (including Xenogears and series boss rush objectives).
- Fixed a crash when converting duplicate units to shards during awakening/EX awakening, which removed the units without giving the shards.
- Fixed unit exchanges in the ticket exchange shop being refused.
- The game now finishes downloading the new data before it opens. This fixes the missing summon banners, "Connection error" on stages, the old Guard Mog menu and the reduced unit limit that appeared right after updating to v0.1.35.
