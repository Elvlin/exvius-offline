# Exvius Offline v0.1.4

Fixed a startup crash that could happen when opening the game from Android's installer after an update.

This version also includes v0.1.3's fresh-start fix: New Game begins with the opening sequence, with the tutorial and Earth Shrine Entrance uncompleted. Existing campaigns retain their earned progress when updating.

Your downloaded game data is reused. New Game backs up your previous campaign before replacing it.

Known issues carried over: startup is still slightly over one minute on the test phone, and the Home TAP graphic and some shop header artwork still need fixes.
