# Game data

The app downloads the complete preserved game data automatically on its first launch. There is no need to choose individual chapters or events.

[`latest.json`](latest.json) lists the current data version, download links, file sizes and checksums. The large data files are attached to the matching [GitHub release](https://github.com/Elvlin/exvius-offline/releases).

After installation, the files stay on the device for offline play. Updates reuse unchanged data parts. Your campaign save is separate from these downloadable files.
